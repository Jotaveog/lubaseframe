# Lubase Frame

Site editorial para StoryMaker, Pre-Wedding e casamentos em Vitoria - ES.

## Rodar localmente

Abra `index.html` no navegador. O projeto nao depende de build ou instalacao de pacotes.

## Substituir assets

- Imagens: `assets/images/`
- Videos: `assets/videos/`

As imagens demonstrativas estao referenciadas no HTML por URLs do Unsplash para que o layout seja visualizado imediatamente. Substitua os `background-image` e `src` pelos arquivos finais do profissional.

O item de video esta preparado com `data-source="assets/videos/portfolio-01.mp4"`; quando o arquivo final estiver disponivel, adicione um `source` dentro do elemento `video`.
